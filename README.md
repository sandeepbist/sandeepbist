### A little about me

I'm Sandeep. I like turning random ideas into things I can actually use, click, run, or play with.

Some projects start with a problem I want to solve. Others start with “I wonder if this would work.” Both tend to end up here.

I enjoy figuring out what happens under the hood as much as making the result feel good to use.

### Things I keep coming back to

- **Useful tools** — small fixes for everyday friction.
- **Interactive experiences** — things that respond, move, and invite you to explore.
- **Systems and automation** — understanding the moving parts, then making them work together.
- **Creative experiments** — following an idea even when I don't know where it leads.

### On my workbench

Tinkering with open source tools, automating daily tasks, and exploring Rust and WebGL.

The project changes. The curiosity stays.
